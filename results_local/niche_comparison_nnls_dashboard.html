The headline. The Q1 effect itself barely moved. What moved is whether it can be measured: seed noise that used to be as large as the effect is now 3–5× smaller than it. Q1 is statable as a number for the first time.

Method

Why the numbers moved

The baseline transfer gave each Leiden cluster one label by argmax correlation against a reference centroid. Cells of the contested EN-IT subtypes never exceeded ~26% of any scGPT cluster, so that argmax could never land on them. Non-negative least squares instead fits each cluster mean as a non-negative mixture of all 35 reference centroids, so a type present at 26% surfaces as a 0.26 weight rather than vanishing.

Audit

Composition has to read the mixture, not the labels

NNLS still writes one hard label per cell — the mixture's argmax — for downstream compatibility. In the scGPT arm that argmax still never lands on the contested types, so composition built from hard labels would recover nothing. Every composition below is the mean mixture vector per domain.

Q1 · annotation axis

Does the annotation method change niche composition?

Raw cosines do not compare across the two transfers. NNLS composition vectors are dense over all 35 types; the baseline's were sparse over each arm's reached labels only (scVI 16–17, scGPT 10–13) with partly disjoint support. Cosine between dense vectors runs higher regardless of whether the arms agree. The matched−mismatched gap cancels that and is the figure to cite.

gap = median cos(scVI[d], scGPT[d]) − mean cos(scVI[d], scGPT[d′]) over d ≠ d′

Reproducibility

The spread that made Q1 unstatable

Seed-to-seed spread of composition agreement. The baseline figure varies only the scGPT seed — 10 seeds, one arm. NNLS varies both arms across 25 seed pairs and is still several times tighter.
