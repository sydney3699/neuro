# neuro

## Data

This analysis uses publicly available data deposited on Zenodo and CELLxGENE Discover:

- **MERFISH and Visium data**: Qian et al. 2025, *Nature*. [Zenodo 14422018](https://zenodo.org/records/14422018) (CC-BY 4.0)
- **Reference scRNA-seq**: Braun et al. 2023, *Science*. Available via [CELLxGENE Discover](https://cellxgene.cziscience.com/collections/4d8fed08-2d6d-4692-b5ea-464f1d072077)


### Data files used
